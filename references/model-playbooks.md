# 模型适配手册（Model Playbooks）

各家模型的提示词口味不同。**先看用户点名哪个；没点名默认 Veo 3 版 + 一条通用版。**

版本随时在变，下面记的是 2025 年底的实操观察，具体参数以各家当前文档为准。真正稳定的部分是：格式偏好、长度容忍度、音频能力、多镜能力。

## 速查表

|---|---|---|---|---|---|---|
| Veo 3 / 3.1 | 散文段落 | 120–200 词 | ✅ 对白+音效 | ❌ | ✅ 首帧 | 提示词内否定句 |
| Sora 2 | 叙事散文 | 150–220 词 | ✅ 对白+环境 | ❌ | ⚠️ | 提示词内 |

## Veo 3 / 3.1

- **口味**：连贯散文。它读逻辑，不读关键词表。因果写清楚（`he pushes the door, and the hinge gives`）比堆形容词有效。
- **音频**：这是它最大差异点。环境音、拟音、对白、配乐都能给。写完画面加一句 `Audio: ...`。
- **对白**：引号内直接写，标注语言与语气：`he says in Mandarin, quietly: "……"`。它会做口型。**务必加 `no subtitles`**，否则容易烧字幕。
- **长度**：太短会自己加戏，太长会丢后半段。120–200 词最稳。
- **运镜**：能吃复合运动，但要连贯（`a slow push-in that drifts slightly left`），不要两条互斥指令。
- **默认时长**：单段约 8s。要 15s 以上就分镜。
- **坑**：多人同框容易糊；快速动作会糊；画面文字必糊（直接禁止）；镜像文字、招牌、书页都别指望。

## Sora 2

- **口味**：叙事散文，越像小说越好。它对**物理**极敏感——重量、摩擦、惯性、布料怎么动、水怎么溅。写这些，成片质量立刻上一档。
- **结构**：`A {N}-second {size} shot.` 开头，然后主体、动作、环境、光、镜头、风格。
- **对白**：支持，写法同 Veo。台词要短，口型才跟得上。
- **一致性**：支持角色/物体跨镜延续，但仍要靠固定串 + 首帧图双保险。
- **坑**：抽象抒情词它会真的拍成「抽象画面」；复杂手部动作仍会崩；长镜头结尾容易自己加动作，用「停住」句收尾。

## Kling 2.x（2.1 / 2.5）

- **口味**：关键词堆叠，逗号分隔。`景别, 主体, 动作, 场景, 光, 运镜, 焦段, 风格`。长句、从句、文学化描述会降质。
- **负面词**：独立字段，务必填。`extra limbs, deformed hands, text, watermark, morphing face, distorted perspective`
- **首尾帧**：这是它最强的地方。同一角色跨镜头，用同一张首帧图 + 简短动作描述，比写一百字描述稳得多。
- **运镜**：有独立的运镜控制面板时，提示词里就别重复写运镜，容易打架。
- **时长**：5s / 10s 档位；10s 更容易出现中段漂移，重要镜头用 5s。
- **坑**：多人对话几乎不可用；快速转身会糊脸；中文提示词可用但不如英文稳。

## Seedance

- **口味**：短句 + 明确镜头编号。它能在一条提示词里做多镜头，这是稀缺能力。
- **写法**：`镜头1：… 镜头2：… 整体风格：…`。每镜仍要一动作一机位。
- **多镜的代价**：镜头越多，每镜的有效分辨率越低。3 镜以内最稳。
- **坑**：镜头之间的连贯性靠「视觉钩子」（同色、同形状、同运动方向），否则像拼贴。

## Hailuo / MiniMax

- **口味**：极简。`[运镜] 主体 动作, 场景, 光`。写多了它反而乱。
- **强项**：人物表情与微动作，尤其亚洲面孔，比同价位模型稳。
- **坑**：复杂运镜会抖；长提示词会丢掉后半段；不要指望它读对白。

## Runway Gen-4

- **口味**：它不是文生视频优先，而是**图生视频**优先。提示词只描述运动与镜头变化，风格由首帧图决定。
- **写法**：`{subject} {action}. Camera: {move}. {light change}`
- **强项**：镜头运动平滑、构图稳定、风格统一（因为风格来自图）。
- **坑**：纯文字生成质量一般；提示词里写风格词几乎无效；不支持音频。

## Wan 2.2 / 通义万相

- **口味**：中文可直接用，动词越朴素越好。`一个女人在厨房切菜，镜头缓慢推近，窗外的光打在她侧脸上`
- **强项**：中文语义理解好，国风/写实题材稳定。
- **坑**：修辞和比喻会被字面执行；复杂运镜弱。

## Pika / Luma / Vidu（简述）

- 都偏「短、稳、图生视频」。提示词 30–50 词，只写主体 + 动作 + 一个运镜。
- 不要写多镜、不要写对白、不要写风格长句。

## 图像 → 视频：一致性的真正解法

文字描述只能做到「大致像同一个人」，**首帧图才能做到「就是同一个人」**。

标准流程：

1. 先用图像模型出**角色定妆图**（正面、半身、中性光、纯背景），一张就够。
2. 每个镜头先用这张定妆图 + 场景描述，出**该镜首帧**。
3. 用首帧跑 image-to-video，提示词只写动作与运镜。
4. 关键转场用**首尾帧**：给模型「从这张图运动到那张图」，比任何文字都准。

配套规则：

- 定妆图的描述串 = 提示词里的 `{{CHAR_A}}`，两处必须逐字一致。
- 同一场景的所有镜头用同一张场景参考图。
- 不要用不同来源的图（不同模型、不同光位）混着做同一角色，会分裂。

## 参数与重试

| 项 | 建议 |
|---|---|
| 画幅 | 竖屏 9:16（短视频）、横屏 16:9（叙事）、2.39:1（电影感）、1:1（广告） |
| 时长 | 单镜 4–6s 最稳；8s 是上限；超过就分镜 |
| 运镜强度 | 有该参数时用低档（0.3–0.5）；运镜靠提示词精确描述，不靠强度堆 |
| 种子 | 固定 seed 才有可比性；调提示词时不要同时改 seed |
| 重试 | 同一提示词跑 3 次取最好；连续 3 次都崩，说明提示词有问题，不是运气 |

**重试诊断表**

| 现象 | 判断 | 动作 |
|---|---|---|
| 3 次都糊脸 | 描述串有歧义 | 缩短人物描述，只留 3 个记忆点 |
| 3 次都乱动 | 动作太多 | 砍到一个动作 |
| 3 次都换风格 | 风格词太多/互相冲突 | 只留一句 look |
| 越好越差 | 提示词太长 | 砍到 120 词，先保动作与光 |
| 首帧对、后面漂 | 时长太长 | 拆成两镜，或降到 5s |

## 生成顺序建议

1. 先做 **poster frame 那一镜**。它定调，也验证角色描述串对不对。
2. 再做出场镜（S01），它决定观众第一印象。
3. 其余按叙事顺序做，每做一镜就把首帧存下来给下一镜当参考。
4. 最后做结尾镜——它最难，因为要「停住」，也最容易被模型加戏。
5. 全部出来后再统一调色/配乐；不要在生成阶段追求最终影调。
